# Lung Cancer Prediction Web Application

A Flask-based web application for predicting lung cancer risk using machine learning models.

> ⚠️ **Disclaimer:**  
> This application is developed for educational and research purposes only. The predictions generated by this application are based on machine learning models and should not be considered a medical diagnosis or a substitute for professional medical advice, diagnosis, or treatment. Always consult a qualified healthcare professional for medical concerns.

---

## 📌 Project Overview

This project is a web-based Lung Cancer Prediction application developed using **Python, Flask, HTML, CSS, JavaScript, and Machine Learning**.

The application provides a simple web interface where users can enter patient-related information and receive a prediction from trained machine learning models.

The project includes multiple machine learning models:

- Logistic Regression
- Random Forest
- Naive Bayes

The trained models are integrated into a Flask web application for prediction.
